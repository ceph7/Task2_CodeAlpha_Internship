# EduLearn – High-Fidelity UI Design (Educational Platform)

## 📌 Project Overview
This project is **Task 2** of my UI/UX Design Internship at **CodeAlpha**.
The goal was to take the low-fidelity wireframe created in Task 1 and transform it into a complete **high-fidelity UI design** for an **educational platform**, applying real visual design decisions: color, typography, iconography, imagery, and interactive components — all grounded in core UI/UX principles.

## 🎯 Objective
Convert the wireframe into a polished, production-ready interface by:
- Defining a cohesive **color palette**
- Selecting a clear **typography system**
- Designing **buttons, icons, and UI components**
- Integrating **images and illustrations**
- Applying **UI/UX best practices** (hierarchy, contrast, consistency, accessibility, spacing)

## 🛠️ Tools Used
- **Figma** – UI design & prototyping

## 🎨 Design Process

### 1. Wireframe Analysis
Reviewed the low-fidelity wireframe from Task 1 to preserve the validated layout, navigation flow, and content structure before adding visual design.

### 2. Color Palette
A palette was chosen to reflect trust, focus, and approachability — fitting for an educational context — with a primary brand color, secondary accent, and neutral tones for backgrounds and text, ensuring sufficient contrast for readability.

### 3. Typography
A modern, legible typeface system was applied with a clear hierarchy (headings, subheadings, body text) to guide the user's eye and maintain consistency across all screens.

### 4. Buttons & Components
Interactive elements (primary/secondary buttons, cards, input fields, navigation bars) were designed with clear states (default, hover, active) to improve usability and feedback.

### 5. Icons & Imagery
Consistent icon sets and relevant imagery/illustrations were added to reinforce meaning, improve scannability, and give the interface a more engaging, human feel.

### 6. UI/UX Principles Applied
- **Visual hierarchy** – guiding attention to key actions
- **Consistency** – reusable components and styles across screens
- **Contrast & accessibility** – readable text and distinguishable interactive elements
- **Spacing & alignment** – a clean, structured grid system
- **Feedback** – clear button/component states for user interactions

## 📂 Deliverables
- Complete high-fidelity UI mockups (Figma)
- Defined color palette & typography style guide
- Icon and button component library
